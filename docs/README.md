# Apache Flink CDC Documentation

The master documentation uses [Docusaurus](https://docusaurus.io/).
Historical release branches retain their Hugo sources and build scripts.

## Local development

Install Node.js 22 LTS and npm, then run from this directory:

```sh
npm ci
npm start
```

Open <http://localhost:3000/flink/flink-cdc-docs-master/>. The development server
serves one language at a time; use `npm start -- --locale zh` for Chinese.

To build and preview both languages:

```sh
npm test
npm run build
npm run serve
```

The production site is written to `target/`. Internal broken links and anchors
fail the build. Search indexes are generated during the production build.

## Source structure

- `content/`: English Markdown, including the home page and version list.
- `i18n/zh/docusaurus-plugin-content-docs/current/`: matching Chinese documents.
- `i18n/zh/docusaurus-plugin-content-docs/current.json`: Chinese category labels.
- `sidebars.js`: the documentation tree. Add new pages here in source order.
- `static/`: shared images and other static assets.
- `site-metadata.js`: CDC version, release status, Git branch, and older versions.
- `src/`: theme wrappers, styles, and the version interpolation plugin.
- `redirects.js`: compatibility redirects for the previous Hugo aliases.

Use Markdown (`.md`) for ordinary pages and HTML tables. Use MDX (`.mdx`) when
embedding React components. Update both languages when adding or editing a page.
Heading anchors are generated by Docusaurus. Update internal links when changing
headings.
The sidebar keeps the original logo, version, and tree navigation.
Version selection, search, language switching, and the GitHub link use the standard
Docusaurus navbar. The mobile layout uses the Docusaurus navigation drawer.
Tables and code blocks use Docusaurus styling, with a light GitHub syntax theme.

Use `@@VERSION@@` for the CDC version in text, code blocks, or download links.
The remark plugin expands it at build time. Raw HTML images can use
`@@BASE_URL@@fig/example.png`; raw HTML documentation links can use
`@@BASE_URL@@@@LOCALE_PREFIX@@docs/get-started/introduction/`.
Prefer relative Markdown source links for links between documents.

## Deployment and Javadoc

The default deployment prefix is `/flink/flink-cdc-docs-master/`. To build a
separate artifact for a deployment alias, set its prefix explicitly:

```sh
DOCS_BASE_URL=/flink/flink-cdc-docs-release-3.8/ npm run build -- --out-dir target-alias
```

The GitHub documentation workflow builds the site with Node.js, then runs the
existing Maven/Javadoc steps in the Java container. Javadoc remains at
`target/api/java/`. The alias gets its own site build and a copy of Javadoc.
Branches without `package.json` continue to use their original Hugo script.

The committed npm lockfile pins dependency versions. Use `npm ci` for a clean
installation, and commit lockfile updates when changing dependencies with `npm install`.

To build the complete site and Javadoc locally, select Java 11 with SDKMAN and run
`.github/workflows/docs.sh` from the repository root. A site-only build needs no JDK.

## Migration utility

`scripts/migrate-hugo.py` records the one-time conversion from an exported Hugo
source tree. It needs no Hugo build output. Normal builds do not run the migration
script.
